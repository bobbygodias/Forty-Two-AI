# Forty-Two AI — Branding Assets

This directory is reserved for the **canonical FortyTwoAI artwork**.

Do not copy, recolor or rename the inherited PocketPal launcher and present it as the Forty-Two AI logo.

When the original source artwork is added, keep a lossless/vector master here and generate platform derivatives from it:

- `forty-two-ai-logo.svg` or equivalent source master;
- `forty-two-ai-logo.png` lossless master;
- Android adaptive icon foreground/background and `mipmap-*` outputs;
- iOS AppIcon derivatives;
- splash / launch-screen artwork;
- README / distribution artwork.

Generated files must preserve aspect ratio, clear space and the canonical mark. Platform-specific crops are derivatives, not new logos.
